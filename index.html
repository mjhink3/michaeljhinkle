Flagship Build  ·  Multi-City Operational Intelligence Platform
GOATvision
Real-Time Situational Awareness at Metro Scale
Seattle — Full Build DMV — Live Philadelphia — Live

Aggregates 16 live data endpoints across 9 distinct APIs — traffic, transit, ferries, weather, fire dispatch, seismic activity, and flight delays — into a single static HTML file with no login, no backend, and no build step. A rule-based Ops Brief synthesizes every panel into a plain-English situational summary of the metro area in real time.

Expanded to DMV and Philadelphia as live secondary deployments with feature parity. Some data sources — Pennsylvania 511, live traffic cams, PulsePoint emergency dispatch for DMV — require commercial API access or LLC-gated credentials. Those requests are in flight. The architecture is already built to accept them.

Each city runs on a shared Supabase telemetry layer with location-key separation and 90-day rolling data retention. Built to scale to 4-5 cities on a single free-tier instance.
